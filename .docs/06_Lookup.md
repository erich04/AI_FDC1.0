# 全局 Lookup 快码表（真相来源）

> **用途**：定义系统中通过「快码 / 字典 / LOOKUP」管理的**取值集合**。持久化通常存 **快码编码**（字符串或数值，见各类型说明），展示文案以本文档为准。  
> **来源**：下列「财经文档_快码配置」及枚举与设计中心 **v1.0.0（新建财经文档快码配置）** 对齐；若设计中心变更，请同步修订本文档并登记「修订记录」。

---

## 使用规则（R-LOOKUP）

| 规则 | 说明 |
|---|---|
| R-LOOKUP-001 | 字段注释须写明 **快码类型编码**（如 `FDC_CONFIDENTIALITY_LEVEL`）及库中实际存储字段（通常存 `快码编码`）。 |
| R-LOOKUP-002 | 禁止在功能规格或代码中写与本文档不一致的含义；新增取值先改本文档再改实现。 |
| R-LOOKUP-003 | API 可返回 `code` + `label`；持久化以 `快码编码` 为准。 |
| R-LOOKUP-004 | 密级等与权限/脱敏相关的码，业务规则见 `/.docs/03_Security.md`；本文档只定义码表含义。 |

---

## 与数据模型的关系

- `/.docs/01_DataModel.md`：列名、类型、可空、索引。  
- **本文档**：允许取值集合及语义。  
- 冲突时：结构以 01 为准；**码值与含义**以本文为准。
