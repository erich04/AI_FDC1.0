# 前端设计规范

## 开发规范要求

1. 统一性：所有页面均采用统一页面风格和操作逻辑，降低系统维护难度。

2. 便捷性：优化页面布局，简化操作流程，支持多种填写、查询方式，适配不同业务量和操作习惯，提升用户操作效率。

3. 兼容性：适配PC端主流浏览器（Chrome、Edge、Firefox最新版本），支持分辨率≥1366*768，确保页面显示正常、交互流畅。

## 页面规范

### 通用规范
1. 页面风格：页面视觉效果使用商务风格，不同页面设计风格一致，包括颜色、字体、图标等，保持页面的一致性。

2. 页面布局：采用自上而下、左右分区的标准化布局，确保视觉清晰。上下区域和所有区域通过不同容器隔开，避免视觉冲突。

3. 字段规范：必填字段标注“*”，鼠标悬浮显示字段填写说明；输入框、下拉框、文本域等组件样式统一。

4. 特定字段规范：查询条件中如果有”是否启用“，字段默认值为“是”。

5. 交互反馈：操作成功、失败、确认等场景均给出明确弹窗提示；字段输入错误时，实时显示错误提示（字段边框变红，下方标注错误原因）。

### 创建页面规范

1. 页面布局：创建页面采用上下分区布局，上方区域为头信息字段填写区域（表单格式，可折叠），下方区域为明细行字段填写区域（表格格式，可折叠）。

2. 字段布局：表单字段每行不超过4个字段，同一列字段描述右对齐，输入框大小为180px，输入框与字段描述间距10px；表格字段每个字段占用一列，字段之间间距10px。

3. 按钮规范：创建页面默认具备提交、保存、取消按钮，提交按钮显示为主要按钮，按钮间距统一10px，位置位于页面右下角。

### 查询页面规范

1. 页面布局：查询页面采用上下分区布局，上方区域为查询条件区域，下方区域为查询列表区域。

2. 查询条件区域：查询条件使用查询表单，每个查询条件输入框宽度为180px，查询条件间距10px，一行最多5个查询条件，查询条件需要自适应屏幕分辨率调整布局，查询条件超过两行要具备查询条件折叠展开功能。查询表单只有查询和重置按钮，两个按钮位置靠最右侧。

3. 查询列表区域：查询列表区域采用表格格式，同一列字段描述右对齐，列宽为180px，表格字段每个字段占用一列，字段之间间距10px。

4. 按钮规范：页面默认具备导入、导出按钮，按钮间距统一10px，位置位于查询列表上方靠左。

5. 分页规范：页面每页默认显示20条数据，用户可以根据需要调整每页显示条数，调整后页面自动刷新，页码根据调整后的条数自动调整。条数可调整为20、50、100、200条。

### 详情页面规范

1. 页面布局与字段布局与创建页面相同。

2. 按钮规范：详情页面默认具备取消按钮，位置位于页面右下角。

### 弹窗页面规范

1. 页面布局：弹窗页面采用上下分区布局，上方区域为弹窗标题区域，下方区域为弹窗内容区域。

2. 标题区域：弹窗标题区域采用水平布局，标题靠左显示，标题与操作按钮间距10px。

3. 内容区域：弹窗内容区域采用表单格式，每个字段占用一列，字段之间间距10px。
