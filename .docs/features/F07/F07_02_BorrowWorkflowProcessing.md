## 3. 共性约束（跨场景）

- 每个页面顶部均显示流程节点图。
- 每个页面按钮区均在底部。
- 除申请环节外，流程节点均支持抄送。
- `需求类型` 与 `借阅内容类型` 为同一业务概念，统一 LOOKUP：`FDC_BORROW_ITEM_TYPE`。

## 4. 跨场景规则（汇总）

- **R-0210**：借阅分单节点采用“多人候选+抢单认领”模式；未认领不可编辑分单内容。
- **R-0220**：审批节点支持 `ALL/ANY/SEQ`，策略配置在明细路由级别。
- **R-0230**：办理节点支持 `ASSIGN/CLAIM`，同一明细只允许一个办理任务进入进行中。
- **R-0231**：原件办理借出成功时扣减档案剩余份数；归还确认后回补。
- **R-0202**：除申请环节外，每个流程节点都允许抄送。
- **R-0240**：逾期未归还按天触发催还消息任务。
