# F01_00 基础数据管理总览

## 1. 范围

- 本文档定义 F01 的总体范围与共性约束。
- 子功能详见本目录下 `F01_01` 至 `F01_07`。

## 2. 子功能边界

- 归档主体、文档类型、业务模块、条码规则、编码规则、库房、库位相互独立。
- 每个子功能独立维护数据字典、接口与验收标准。

## 3. 共性规则

- 主键命名、字段后缀、索引命名遵循 `/.docs/01_DataModel.md`。
- 审计字段（创建人、创建时间、版本号）为必填共性字段。
- 状态字段统一使用 `_STATUS`，有效标识使用 `_FLAG`。

## 4. 共性权限与安全

- 权限模型对齐 `/.docs/03_Security.md`。
- 变更类操作必须记录审计日志（谁、何时、改了什么）。

## 5. 共性验收

- 每个子功能应至少包含：主流程、异常流、权限校验、审计日志、回归用例。
