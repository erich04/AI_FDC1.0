# 财经文档系统原型演示

## 简介
这是一个财经文档系统的HTML原型demo，用于向开发团队展示系统的主要功能和界面设计。

## 文件结构
```
financial_document_system/
├── index.html              # 主页面 - 系统入口
├── pages/                  # 功能页面
│   ├── document_search.html    # 文档查询页
│   ├── document_detail.html    # 文档详情页
│   ├── document_edit.html      # 文档编辑页
│   ├── document_create.html    # 文档创建页
│   ├── data_maintenance.html   # 数据维护页
│   ├── attachment_preview.html # 附件预览页
│   ├── import_query.html       # 导入查询页
│   └── my_exports.html         # 我的导出页
└── README.md               # 说明文档
```

## 功能说明

### 1. 主页面 (index.html)
- 展示系统的两个主要功能入口
- 文档查询：用于搜索和查看文档
- 数据维护：用于管理文档数据和创建新文档

### 2. 登录页面 (login.html)
- 系统登录界面
- 提供用户名和密码输入
- 登录按钮和重置功能

### 3. 文档查询页 (document_search.html)
- 提供多条件筛选功能
- 支持文档类型、归档主体、业务模块、档期等筛选
- 显示文档列表，包含所有关键信息
- 点击文档编号可跳转到详情页
- 支持批量导出功能，导出成功后可跳转到"我的导出"页面
- 批量导入查询按钮，弹窗标题为"批量导入查询"

### 4. 文档详情页 (document_detail.html)
- 展示文档的完整信息
- 包含文档基本信息、扩展信息、归档信息等
- 状态标签与标题在同一行
- 显示文档附件列表，操作列使用图标按钮
- 点击附件的"预览"按钮可查看附件内容
- 取消了返回按钮

### 5. 文档编辑页 (document_edit.html)
- 文档编辑界面
- 包含与创建页相同的表单结构
- 支持保存和取消操作

### 6. 文档创建页 (document_create.html)
- 完整的文档创建表单
- 包含基本信息、扩展信息、归档信息三个部分
- 所有必填字段都有标记
- 提供提交和取消功能

### 7. 数据维护页 (data_maintenance.html)
- 展示所有文档的列表
- 提供编辑、删除等操作按钮
- "文档创建"按钮可跳转到创建页面
- 支持批量操作功能
- 批量导入查询按钮，弹窗标题为"批量导入查询"

### 8. 附件预览页 (attachment_preview.html)
- PDF文档的预览界面
- 包含页导航、缩放控制等功能
- 带有水印的安全预览模式
- 底部显示所有附件的缩略图

### 9. 导入查询页 (import_query.html)
- 导入任务查询界面
- 支持按文件名称、任务类型、状态、时间等筛选
- 显示导入任务列表和详细信息

### 10. 我的导出页 (my_exports.html)
- 导出任务管理界面
- 显示导出任务列表
- 支持下载和删除操作

## 功能亮点

### 批量导出功能
1. 在文档查询页选择一个或多个文档
2. 点击"批量导出"按钮
3. 系统显示导出成功提示
4. 可通过链接跳转到"我的导出"页面查看导出结果

### 附件管理
1. 文档详情页显示附件列表
2. 支持附件预览和下载
3. 附件预览页提供水印保护

### 多条件筛选
- 各页面均提供丰富的筛选条件
- 支持展开/收起更多筛选条件

## 使用说明
1. 直接用浏览器打开 `index.html` 即可开始演示
2. 所有页面间的跳转均已实现
3. 演示数据为静态数据，仅用于展示界面和交互流程
4. 批量导出功能已实现完整的交互流程

## 技术栈
- HTML5
- Tailwind CSS (通过CDN)
- Vanilla JavaScript
- Material Icons

## 注意事项
- 这是一个纯前端原型，不包含后端逻辑
- 所有数据都是静态的，仅用于演示
- 实际项目中需要集成真实的PDF预览组件和文件管理系统
