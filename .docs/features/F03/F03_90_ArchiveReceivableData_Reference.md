> 归属：后续应移动/归并到对应功能（例如 F02 应归数据、或独立的“导入导出/任务中心”功能）。

## 3. 导入查询页（import_query.html）要点（参考）

- 筛选条件：文件名称、导入任务类型、导入状态、导入时间（范围）
- 列表字段：文件名称、导入任务类型、导入时间、导入状态、导入总条数、导入成功条数、运行时间、总耗时、导入结果（含：结果查询/重新查询/结果导出）
- 状态示例：成功/失败/部分成功

**规格归并**：工作空间「导入查询」的正式条款（系统通用、与文档类型/公司无关、接口与 AC）以 `F03_06_MyImportQueries.md` 为准；本文件保留原型与旧规格摘录。

## 4. 批量导入查询弹窗（旧规格）

- 标题：批量导入查询（Batch Import Query）
- 内容：
  - 下载导入模板（某业务页打开弹窗时，旧规格示例为文档查询页按**所选文档类型**区分模板；具体联动由**各调用方**页面决定，**不改变**工作空间「导入查询」作为全站任务中心的通用性，见 `F03_06`）
  - 选择文件（支持 Excel：`.xlsx/.xls`，支持拖拽）
- 按钮：取消/确定（确定触发“批量导入查询服务”）

## 5. 与 F03 的边界声明（必须遵守）

- F03 文档查询可保留“批量导入查询入口”，但其详细规则/接口/数据模型**不得混入** F03 主规格文件；工作空间导入任务列表以 `F03_06` 为 SSoT。  
- F03 验收与测试用例不包含应归档数据管理链路中**仅**属于应归档数据域的部分；工作空间「导入查询 / 导出查询 / 我的草稿」的验收见 `F03_06`、`F03_05`、`F03_07`。
