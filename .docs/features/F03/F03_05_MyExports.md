# F03_05 我的导出

> 参考：HTML `reference_html/pages/my_exports.html`。

**工作空间口径**：菜单或工作空间中亦称「**导出查询**」。本能力与文档查询列表页上的文档类型、公司编码、业务模块等筛选条件**无绑定关系**；仅按当前用户（及 `/.docs/03_Security.md` 约定的 RBAC扩展）展示导出任务。

**全系统通用**：导出任务中心服务于**整个平台**；文档查询「批量导出」、其他业务列表或后台作业均可创建任务，并在本页（导出查询/我的导出）统一查看，**并非**文档查询专属功能。

## 1. 场景

- **S-01 查看导出任务列表**：进入“我的导出”页面，查看任务ID、导出时间、导出内容、状态、文件大小
- **S-02 下载导出文件**：状态为“已完成”时可下载
- **S-03 删除导出任务**：删除任务记录及其文件（按策略可能仅逻辑删除）

## 2. 页面字段（来自原型）

| 列 | 说明 |
|---|---|
| 导出任务ID | 如 `EXP-20260326-001` |
| 导出时间 | 时间戳 |
| 导出内容 | 如 “会计凭证 (3条)” |
| 状态 | 已完成 / 处理中（原型示例） |
| 文件大小 | 已完成时显示大小；处理中可为 `-` |
| 操作 | 下载、删除；处理中可出现“取消”（原型按钮为 disabled 示例） |

## 3. 规则与策略

- **R-ME-001 可下载条件**：仅当任务状态为“已完成”且用户具备下载权限。
- **R-ME-002 删除策略**：删除后任务不可在列表中出现；文件若已生成，应同步清理或标记过期（与留存策略一致）。
- **R-ME-003 可见性**：仅展示“当前用户”任务（或按角色扩展为管理员可查看全量，需在安全文档明确）。

## 4. 接口（建议）

> 遵循 `/.docs/05_API_Conventions.md`，与 `F03_04` 中 `export-tasks` 一致。`{id}` 为数值型主键。

| 资源路径 | 方法 | 用途 |
|---|---|---|
| `FDC_URL/export-tasks/page` | GET | 我的导出任务列表（分页） | Query：`pageNumber`、`pageSize` |
| `FDC_URL/export-tasks/{id}` | GET | 单个任务详情/状态 |
| `FDC_URL/export-tasks/{id}/download` | GET | 下载导出文件 |
| `FDC_URL/export-tasks/{id}` | DELETE | 删除导出任务及文件 |

## 5. 验收标准（AC）

- **AC-01**：用户能在“我的导出”看到自己发起的导出任务，并按时间倒序展示。  
- **AC-02**：任务状态为“已完成”时，点击下载可成功下载文件。  
- **AC-03**：删除任务后，该任务不再出现在列表中；重复刷新保持一致。

#### 5.2.2 分页面规格
##### P-05 《我的导出》

###### （1）页面类型与整体布局
- **页面类型**：列表页
- **布局骨架**：
  - **L1** Header：返回首页 + 搜索框 + 用户信息
  - **L2** 面包屑导航：首页 / 导入导出 / 我的导出
  - **L3** 标题区：我的导出
  - **L4** 主内容区：导出任务列表表格（含操作列）
  - **L5** 分页与页容量选择
- **原型与设计**：`reference_html/pages/my_exports.html`

###### （2）分区 → 模块拆解

**〔L2 面包屑导航〕— 模块 M1（精简版）**
| 元素 | 字段名-英文 | 链接逻辑 |
|---|---|---|
| 首页 | Home | 跳转首页 |
| 导入导出 | Import And Export | 跳转导入导出入口（原型为 `#`） |
| 我的导出 | My Exports | 当前页面 |

**〔L4 主内容区〕— 模块 M2：导出任务列表表格（全量版列字段）**
| 列名 | 字段名-英文 | 类型 | 展示逻辑/取值来源 | 交互（链接/操作） | 备注 |
|---|---|---|---|---|---|
| 导出任务ID | Export Task ID | 文本 | export_task_id / 任务标识 | 无 | 示例：`EXP-20260326-001` |
| 导出时间 | Export Time | 日期时间 | 创建时间/提交时间 | 无 | 示例：`2026-03-26 10:30:00` |
| 导出内容 | Export Content | 文本 | 导出范围/条数汇总 | 无 | 示例：`会计凭证 (3条)` |
| 状态 | Status | 标签 | export_status（原型：已完成/处理中） | - | 处理中显示黄色/已完成显示绿色（原型样式） |
| 文件大小 | File Size | 文本 | 成功后显示大小；处理中为 `-` | - | |
| 操作 | Operations | 按钮组 | 根据状态启用/禁用 | 下载、删除；处理中可出现“取消”（原型 disabled） | 行内操作列（右对齐） |

**〔L4 主内容区〕— 模块 M3：行内操作按钮（全量版）**
| 操作 | 按钮名称 | 状态可见/启用条件 | 点击后行为 |
|---|---|---|---|
| 下载 | 下载 | 状态=已完成 且有下载权限 | 调用 `export-tasks/{id}/download`，记录审计 |
| 删除 | 删除 | - | 删除任务记录及其文件（或逻辑删除），删除后从列表移除 |
| 取消（原型示例） | 取消 | 状态=处理中 | 原型示例为 disabled（待与实现策略对齐） |

**〔L5 分页〕— 模块 M4：分页控件（全量版）**
| 控件 | 类型 | 说明 |
|---|---|---|
| 总记录数 | 文本 | 原型示例：共 3 条记录 |
| 页码导航 | 按钮 | 支持上一页/下一页、当前页高亮 |
| 每页条数 | 下拉 | 原型示例：10条/页、20条/页、50条/页 |
