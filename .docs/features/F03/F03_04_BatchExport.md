# F03_04 批量导出

> 参考：旧规格 `1.3 规格设计-批量导出`（弹窗提示） + 文档查询页批量导出按钮逻辑 + 我的导出页原型。

## 1. 场景

- **S-01 从文档查询列表发起导出**
  - **输入**：0条或N条勾选记录
  - **处理**：
    - 0条：导出“当前查询条件对应的结果集”
    - N条：导出“勾选集合”
  - **输出**：创建导出任务；弹窗提示“导出提交成功…稍后到 导入导出 > 我的导出 查看”

## 2. 交互规格（旧规格）

### 2.1 成功提示弹窗

- **标题**：提示（Info）
- **内容**（旧规格）：
  - 绿色对钩图标
  - 文案：导出提交成功，系统正在处理，稍后请到 **导入导出 > 我的导出** 中查看导出结果。
  - 文案中的“导入导出 > 我的导出”为可点击链接，点击跳转我的导出页
- **按钮**：确定（Confirm）—关闭弹窗

## 3. 规则与策略

- **R-EX-001 权限控制**
  - 具备“文档列表导出/导出权限”才可发起导出
  - 无权限：按钮置灰或不可见（以 `/.docs/03_Security.md` 为准）

- **R-EX-002 导出内容定义**
  - 未勾选：导出当前查询条件的结果集（可能很大，需后端限制/异步）
  - 已勾选：仅导出勾选集合

- **R-EX-003 异步任务**
  - 导出采用异步任务；前端仅拿到 `export_task_id`
  - 后续在“我的导出”轮询或刷新查看状态

## 4. 接口规范（建议）

> 遵循 `/.docs/05_API_Conventions.md`。文档列表导出走 `documents/export`；导出任务实例为扁平资源 `export-tasks`。`{id}` 为数值型主键。

| 资源路径 | 方法 | 用途 | 幂等 |
|---|---|---|---|
| `FDC_URL/documents/export` | POST | 提交文档列表导出任务 | 建议 `Idempotency-Key` |
| `FDC_URL/export-tasks/page` | GET | 当前用户导出任务列表（分页） | Query：`pageNumber`、`pageSize`、`filter.*` |
| `FDC_URL/export-tasks/search-page` | POST | 导出任务列表（复杂筛选 + 分页，可选） | 请求体含 `filter` |
| `FDC_URL/export-tasks/{id}` | GET | 单个任务状态/详情 | - |
| `FDC_URL/export-tasks/{id}/download` | GET | 下载导出结果文件 | - |
| `FDC_URL/export-tasks/{id}` | DELETE | 删除任务及关联文件 | - |

## 5. 可观测性与审计

- 记录：发起人、筛选条件摘要/勾选数量、导出类型、结果文件大小、完成时间、失败原因。

## 6. 验收标准（AC）

- **AC-01**：未勾选记录点击“批量导出”，系统创建任务并提示可跳转“我的导出”。  
- **AC-02**：勾选N条记录点击“批量导出”，导出内容仅包含勾选集合。  
- **AC-03**：导出任务在“我的导出”可见，状态从“处理中”到“已完成/失败”。
